Plan limits come from the Claude desktop app's own accounting (plan-usage-history.json in each account's desktop folder) and refresh about every 5 minutes while that account's desktop app is open. Token counts come from Claude Code transcripts; dollar figures are what the same tokens would cost at API list prices — a way to compare accounts, not a bill.

Several Claude Code sessions side by side, each on any account. Type a message in a pane to send it. Open existing ones from Sessions or Tasks.

Each message runs claude -p --resume under the pane's account, so panes work in parallel and keep their history. Plan is read-only; Ask refuses tools that need approval (continue in Terminal for those); Edit may change files. Don't reply to a session that is also open in a Terminal — the two would branch apart.
